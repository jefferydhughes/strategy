## Original Suggestions Received

- Add housing details and a booking system to the Kingswood website.
- Reference examples identified in the email:
  - UNB Summer Hotel Page
  - StFX Summer Hotel Booking Page
- Intended benefit: improve credibility and make it easier for tourism operators to review Kingswood housing options.

### 2. Public Booking Platforms

- Use public booking platforms such as **VRBO** to advertise rooms to the general public.
- The email notes that many booking platforms can integrate with the institutional website.

### Steps Required for Implementation

- **Room and Building Photos:** Create high-quality images for marketing.
- **Linens and Pillows:** Purchase these as bookings are confirmed in order to avoid unnecessary upfront costs.
