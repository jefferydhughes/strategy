# Kingswood Data Request Tracker

**Purpose:** Record every piece of institutional data requested and received for the Kingswood University Growth Strategy, with its date and source, so provisional Prioritization scores can be replaced with verified figures.  
**Created:** October 1, 2026  
**Owner:** Jeff Hughes

> **Rules.** Every value entered here carries the date received, the source (office, person, document or system), and the period it covers. Partial numbers are welcome; mark them Partial. Data from an institutional record or system is **Confirmed**; an estimate from staff is labelled **Hypothesis** until verified (README Section 7). Do not overwrite a value. Add a new dated entry and note which entry it supersedes.
